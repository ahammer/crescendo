## Evidence-backed change in this PR

At **October 1 19:56:03 UTC**, MetalRain's project orchestrator crashed with `BadMapError` in
`model_for_update/2`: an emitted Codex payload was a string containing manifest text, and model
bookkeeping called `Map.get` on it. The following log line records the project's slots being
freed, and the ledger records three simultaneous interruptions for #991, #997 and #998.
AppServer deliberately emits non-object JSON as `other_message` and malformed protocol candidates
as string payloads. Current main still assumes a map in model extraction, turn-event recording
and optional notification capture. A normal diagnostic message must not destroy project ownership
or interrupt useful workers. [L; `Codex.AppServer` and `Orchestrator` source inspected in this run]

This PR uses one envelope reader for those three consumers, preserves raw diagnostic
messages, ignores non-map bookkeeping fields, and continues processing subsequent valid reroute,
usage and completion events. AppServer also rejects non-string reroute targets before they can
persist in native model metadata and reach later usage notifications.
It adds no timeout, routing option, dependency or service endpoint.
An OTP regression sends the exact scalar shape from the log, arrays, numbers, booleans, null and
malformed params, checks health synchronously, then proves valid accounting and optional capture
still work. `SPEC.md`, `elixir/README.md` and `docs/crescendo.md` document the behavior.

Review reproduced a malformed `toModel` value reaching later usage and completion messages
through AppServer metadata. A native lifecycle regression preserves the last valid model across
scalar, object, array and null targets, while retaining diagnostics and accepting valid reroutes.
Shared test setup stops the test application's default scheduler so it cannot dispatch additional
workers into later lifecycle fixtures.

The regression control failed on original main with the logged `BadMapError`; after the fix,
65 focused status/accounting/thread-lifecycle tests passed, including the previously failing
drain-fixture seed `806293`. The required
`cd elixir && mise exec -- make all` passed under the shared machine lease: format, public specs
and strict Credo checks; 526 tests, zero failures and six skipped; 100% coverage for non-ignored
modules; and Dialyzer with zero errors. PR-description validation and `git diff --check` passed.
